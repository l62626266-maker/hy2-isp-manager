# 本地终端交互优化（开发版）

状态：管理器 `0.3.0-dev`，证书守护器 `0.1.1-dev`；优化版使用独立测试分支 `dev/terminal-ui-0.3.0`，不替换 `main` 或稳定发布，未部署 VPS。

## 已实现

- 安装后提供 `hy2` 快捷入口，保留 `hy2-manager`；普通用户调用时请求 sudo 权限，不覆盖其他程序已有的 `hy2` 文件。
- 修复命令替换导致 stdout 非终端、错误跳过 whiptail 的问题，改为检查 stdin/stderr；有终端时使用方向键交互，没有终端时保留数字菜单。
- 首次安装首页提供自定义域名安装向导；已有安装直接进入节点面板，不显示“全新安装”；仅有旧版直连时保留只读兼容视图，不直接覆盖旧配置。
- 首页显示各节点进程状态及一份共享证书状态，不展示密码、代理账号或完整节点链接；服务运行不等于端到端连通性。
- 从列表选择节点后查看链接/二维码、修改端口、更换 ISP 或删除，免输节点 ID；直连节点不显示更换 ISP，仍有 ISP 时禁止删除直连。
- 输入支持取消、返回及 EOF 退出，确认操作默认选择取消，隐藏输入也支持 `:menu`。
- ISP 支持隐藏粘贴 `socks5://user:password@host:port` 或 `host:port:user:password`，IPv6 使用 URL 形式；URL 的特殊字符需百分号编码，解析过程不执行 shell、不将凭据放到进程参数或错误日志。
- ISP 原有 TCP/认证/出口测试保留，测试通过后才进入配置替换；UDP 探测不是实际数据包转发保证。
- 修改节点端口保留认证及 ISP 配置，冲突检查包含已停止节点的登记端口；失败或可捕获的中断会恢复旧配置、URI、状态与防火墙规则，恢复失败保留事务备份。
- NAT 只修改公网端口时不重启服务；服务商映射仍须人工调整，客户端链接也需更新。
- 证书仍只维护一套；纯管理器部署按 root 所有且不可被组/其他用户写入的节点记录更新服务/端口目标，新增、删除、改端口均会体现在下一次守护检查或部署中，不改写原守护配置。
- 手工部署、混合部署或不同证书目录维持显式守护配置；可在守护配置设置 `AUTO_DISCOVER_MANAGER=0` 停用自动发现。
- 证书预警改为说明剩余天数，不再把固定 30 天阈值表述为 Certbot 必须续期的时间。

## 菜单结构

```text
hy2
├─ 未安装：开始安装 / 退出
└─ 已安装：节点列表及一份证书状态
   ├─ 管理节点 → 选择节点 → 详情 / 修改端口 / 更换 ISP / 删除
   ├─ 添加节点 → ISP / 直连
   ├─ 域名与证书 → 状态和续期计划 / 日志
   ├─ 诊断与备份 → 只读诊断 / 备份
   ├─ 高级设置 → 帮助 / 卸载
   └─ 退出
```

## 明确未开放的能力

- **全局更换域名**：没有加入自动迁移按钮，须先设计并验证证书、全部节点链接及守护配置一起切换和回滚，避免把“修改一行域名”误当成安全迁移。
- **Ubuntu 26.04 / 26.10**：只提供带风险提示、默认取消的实验性安装入口，未做真实系统 apt、systemd、Certbot 集成测试。
- **真实 GUI/网络验收**：本地 Windows 测试不证明 Linux whiptail 的视觉效果、真实 VPS 端口可达或客户端连通性。
- **断电/强制终止恢复**：端口事务处理正常失败和 INT/TERM，不能承诺 SIGKILL、断电或磁盘损坏后自动恢复；变更期间不要同时用多个会话修改同一节点。
- 安装器的远程版本和 SHA256 保持对应原稳定发布标签，未创建新 tag；本地开发代码只有使用本地安装器才会被安装，本次未执行安装器。

## 测试入口

所有测试默认将临时文件放在仓库 `.tmp/`，也可显式设置工作区内的 `TMPDIR`；UI 测试 mock systemd、UFW 和 root 文件所有者操作，不操作宿主机服务。

```bash
bash tests/run.sh
bash tests/ui-test.sh
bash tests/cert-guard-test.sh
bash tests/guard-discovery-test.sh
python3 tests/tty-test.py
shellcheck -x hy2-manager hy2-cert-guard install.sh install-cert-guard.sh tests/*.sh
```

`tty-test.py` 在 POSIX PTY 中验证菜单捕获不丢失交互能力，在 Windows 明确跳过；固定 Hysteria 二进制的启动测试和 PTY 测试已配置到 Linux CI，远端验证结果以该测试分支的 GitHub Actions 为准。
