# 本地可靠性修复记录

日期：2026-10-29；修复基于 dev/terminal-ui-0.3.0，以下验证在上传前完成；未发布、未部署。

## 修复范围

- 管理器、守护器和守护器安装器使用同一稳定锁文件；交互冲突立即提示，后台检查和续期最多等待 300 秒；签发禁用目录钩子，首次守护检查不再嵌套申请同一锁。
- 管理状态及通用文件安装、续期钩子和守护器生成文件使用同目录暂存与原子替换；状态还原不会替换锁文件所在目录。
- 防火墙规则先持久记录再开放，删除失败保留归属；停止节点的端口不能被新节点复用。
- 守护器严格验证证书主机名、有效期和密钥，纯管理器部署从受信任状态同步当前域名；DNS-01 不再检查 HTTP 80，旧域名续期不能覆盖新部署。
- 证书部署具备快照、逐步检查、失败/中断回滚和恢复材料保留，只重启原本运行的节点；管理器自动续期使用同一事务边界。
- 修复换域名复用已有证书时漏部署；安装器只移动确认为守护器已接管的管理器钩子，保留手工和混合部署的其他钩子。
- 修复证书刚过期显示，面板状态缓存 2 秒；不可用流量计数不再作为正常数值显示，新生成服务开启 IP accounting。
- 更新备份适用范围：本机管理配置回滚，不包含完整 ACME、独立守护器配置和外部 NAT 设置，不等同整机灾难恢复。

## 设计决定

保留单文件脚本分发，集中内部锁、状态发布和事务接口；直接拆成运行时模块会破坏当前固定版本安装器仅下载单脚本的约定，模块打包迁移不混入本轮可靠性修复。
保留当前开发分支的全部既有未提交改动，没有替用户暂存或提交。

## 验证

- 13 个本地可运行的 Shell 套件通过，包含 31 个域名事务用例、34 个证书回滚用例、29 个首次安装用例、20 个新增可靠性用例和 3 个管理器续期用例。
- 新增故障测试覆盖错误域名前缀、部分发布、SIGTERM、重启/备份失败、停止节点、旧域名、首次守护检查、防火墙账本、原子文件替换和短时过期。
- 6 个首次安装测试随原子发布改造，将注入点由 install 移到 mv；保留原回滚断言，并确认每个注入点实际触发。
- Bash 语法、ShellCheck 0.10.0、git diff --check、待提交文件的敏感信息模式扫描通过。
- 独立只读代码审查完成，发现的实质问题已修复并由回归覆盖。

## 尚未验证的环境

本机是 Windows：真实 Linux flock 竞争、PTY、原生符号链接用例已明确跳过，Linux Hysteria 冒烟与真实 systemd/UFW/VPS/NAT/arm64 连通性未在本机验证；相关可自动化测试已接入 CI，但尚未上传触发远程运行。

## 第二轮：节点事务与 Linux 验证

首次远程 Linux CI 暴露旧版 OpenSSL 在域名不匹配时仍可能退出成功的问题；管理器和守护器现在均要求明确的匹配文本，新增零退出码误判回归。
创建、替换 ISP、重命名、启停及改端口共用节点事务，先快照再修改；写入失败或中断时恢复文件和原运行状态，恢复失败保留材料供人工处理。
替换 ISP 和改端口不会启动已停止节点；主动停止记录当前 Linux boot ID，守护器只对同次开机中明确停用且处于 inactive 的节点免运行/监听告警，failed 或重启后的异常仍告警。
节点记录原子保存名称、端口、ISP 元数据和停止意图；旧记录默认运行意图，备份读取兼容新字段。

本轮仍是开发分支：仓库本地执行安装器使用相邻脚本；原有联网安装器继续固定旧发布标签及校验值，不会因本分支上传而自动更新既有服务器。
新增节点故障、停止意图及证书域名回归已纳入 CI；完整远程运行结果在完成后记录，真实 VPS/systemd/UFW/NAT 连通性仍需目标环境验证。

独立审查未发现阻断问题；非阻断遗留：写入被中断时可能保留受限权限的 `.install.*`/`.state.*` 临时文件，后续可完善清理，不影响当前配置的事务恢复。
